📡 API使用示例

朋友圈截图编辑器 - 完整参数说明和使用示例

⚡ 默认值说明：
  • 点赞数：不传参数时，随机生成 12-30 个点赞
  • 评论数：不传参数时，随机生成 5-12 条评论

📋 接口参数

参数名 类型 必填 默认值 说明
screenshot File 必填 - 朋友圈截图文件
likesCount Number 可选 12-30 点赞人数（1-50）
commentsCount Number 可选 5-12 评论条数（0-20）
newTime String 可选 当前时间 修改后的时间
useSmartDetection Boolean 可选 false 是否使用智能布局检测
phone String 可选 - 用户手机号
nickname String 可选 - 用户昵称

💡 使用示例

示例1: 最简单使用（全部默认）

只上传图片，点赞和评论都用默认值

const formData = new FormData();
formData.append('screenshot', imageFile);

const response = await fetch('/api/modify', {
    method: 'POST',
    body: formData
});

// 结果：
// ✅ 点赞：随机12-30人
// ✅ 评论：随机5-12条（智能匹配主题）

🎯 完整处理流程

async function uploadAndProcess(imageFile) {
    try {
        // 1. 先检查权限
        const checkRes = await fetch('/api/user/check');
        const checkData = await checkRes.json();

        if (!checkData.allowed) {
            alert('今日免费额度已用完！');
            return;
        }

        console.log(`剩余次数: ${checkData.remainingQuota}`);

        // 2. 构建表单数据
        const formData = new FormData();
        formData.append('screenshot', imageFile);

        // 根据需求选择：
        // 方案A: 全部默认（点赞12-30，评论5-12）
        // （不传任何参数）

        // 方案B: 自定义数量
        formData.append('likesCount', 25);
        formData.append('commentsCount', 10);

        // 方案C: 仅点赞不评论
        // formData.append('likesCount', 30);
        // formData.append('commentsCount', 0);

        // 3. 发送请求
        const response = await fetch('/api/modify', {
            method: 'POST',
            body: formData
        });

        // 4. 处理响应
        if (response.status === 403) {
            const error = await response.json();
            alert(error.error + '\\n' + error.upgradeHint);
            return;
        }

        if (!response.ok) {
            throw new Error('处理失败');
        }

        // 5. 下载图片
        const blob = await response.blob();
        const url = URL.createObjectURL(blob);
        const a = document.createElement('a');
        a.href = url;
        a.download = 'modified_moments.png';
        a.click();
        URL.revokeObjectURL(url);

        // 6. 显示剩余次数
        const remaining = response.headers.get('X-Remaining-Quota');
        if (remaining !== null) {
            console.log(`处理成功！剩余次数: ${remaining}`);
        }

    } catch (error) {
        console.error('处理失败:', error);
        alert('处理失败: ' + error.message);
    }
}
✅ 推荐用法：
  • 快速使用：不传任何参数，使用默认值（点赞12-30，评论5-12）
  • 精准控制：传入具体数值，完全自定义
  • 纯点赞模式：likesCount指定数量，commentsCount=0

📊 默认值详细说明

点赞数 (likesCount)

  • 不传参数：系统随机生成 12-30 个点赞
  • 传入0：不添加点赞
  • 传入具体值：使用指定数量（范围1-50）

评论数 (commentsCount)

  • 不传参数：系统随机生成 5-12 条评论
  • 传入0：不添加评论
  • 传入具体值：使用指定数量（范围0-20）
